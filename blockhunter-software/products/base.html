How to reuse it

So wird es wiederverwendet

  • Keep the header and language switcher unchanged.
  • Replace the hero title and body copy for each product.
  • Re-use the same panel, grid, and button styles for consistency.
  • Header und Sprachumschalter bleiben gleich.
  • Nur Titel und Texte werden pro Produkt angepasst.
  • Panels, Grid und Buttons werden fuer Konsistenz wiederverwendet.

Design goals

Design-Ziele

The base focuses on clarity: one strong hero, one explanatory panel, and a predictable path to the next page.

Die Basis konzentriert sich auf Klarheit: ein starker Hero, ein erklaerender Panelbereich und ein klarer Weg zur naechsten Seite.
